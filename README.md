# E-commerce Sales Analysis Dashboard

## 📊 Overview
An interactive Power BI dashboard built to analyze e-commerce sales performance, 
providing insights into profit, revenue, customer behavior, and regional trends.

## ✨ Key Features
- **KPI Cards:** Total Profit, Total Sales Amount, Quantity Sold, Average Order Value (AOV)
- **Category & Sub-Category Analysis:** Sales and profit breakdown by product category
- **Payment Mode Analysis:** Quantity sold by payment type (donut chart)
- **State-wise Performance:** Sales amount across different states (bar chart)
- **Top Customers:** Ranked by sales amount (column chart)
- **Monthly Trend:** Profit trend over time by order month
- **Interactive Filters:** Slicers for State and Order Date Quarter for dynamic exploration

## 🛠️ Tools & Skills Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
